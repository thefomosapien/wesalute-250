# WeSalute × America 250

A campaign landing page built for WeSalute's America 250 collaboration — celebrating 250 years of American service, sacrifice, and the military community. Built with Next.js 15 (App Router), TypeScript, and Tailwind CSS, it serves a single-route experience at `/` designed to honor veterans and active-duty members with a bold, patriotic visual identity.
